## About

The **Baby Pics Project** is a web development project created as part of a web integration course. It is designed for a professional photographer specializing in baby, pregnancy, and newborn photography. The objective is to develop a visually appealing and user-friendly website that highlights the client's work and aligns with her unique domain of expertise.

Since the client does not have an existing graphic charter, this project provides the creative freedom to design a website that reflects her style and the delicate nature of her photography.

## Features

- **Responsive Design**: The website is fully responsive, ensuring a seamless experience across all devices, including desktops, tablets, and smartphones.

- **Gallery Showcase**: A visually appealing gallery to display the photographer's work, categorized by themes such as newborn, maternity, and family portraits.

- **Contact Page**: A dedicated contact page with a form and social media links to facilitate communication with potential clients.
